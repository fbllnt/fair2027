# FAIR Creativity Shop

Protótipo 2027 com portfólio interativo, quatro cases, galerias e filme de Seja ANTI.

## Rodar localmente

```sh
node build.mjs
python3 -m http.server 8000 --directory dist
```

Abra [localhost:8000](http://localhost:8000). As páginas compiladas e as mídias estão em `dist/`. O conteúdo dos cases está em `projects.mjs`.
